# 现代美式 KK 学习站设计

## 目标

把现有的英美音混合单页改造成只教授现代美式 KK 的静态学习站。用户进入首页即可看到完整学习范围、分类、重要性和先后顺序，并能从第 1 课开始逐音学习。

完成标准：

- 全站只出现本规范定义的 41 个现代美式 KK 音素，不再展示英音切换、英式备注、英式例词录音或旧版符号。
- 首页完整展示 6 个阶段和 41 个音，学习顺序、重点易错音和预计时间一目了然。
- 每个音都能完成“标准音 → 发音方法 → 例词 → 最小对立 → 听辨自测”的闭环。
- 手机和桌面浏览器均可使用；学习进度保存在当前浏览器。
- 公开发布到 GitHub Pages；推送 `main` 后自动部署。

## 音标体系

采用 41 音现代美式 KK 记法。

### 元音（17）

1. 核心元音：`/iː/ /ɪ/ /ɛ/ /æ/ /ʌ/ /ə/ /uː/ /ʊ/ /ɑ/ /ɔ/`
2. 卷舌元音：`/ɝ/ /ɚ/`
3. 双元音：`/eɪ/ /aɪ/ /ɔɪ/ /aʊ/ /oʊ/`

### 辅音（24）

1. 爆破音：`/p/ /b/ /t/ /d/ /k/ /g/`
2. 摩擦音：`/f/ /v/ /θ/ /ð/ /s/ /z/ /ʃ/ /ʒ/ /h/`
3. 破擦音：`/tʃ/ /dʒ/`
4. 鼻音：`/m/ /n/ /ŋ/`
5. 流音和半元音：`/l/ /r/ /j/ /w/`

不再把 `/tr/ /dr/ /ts/ /dz/` 当作独立音素，也不再使用英式 `/ɒ/ /ɜː/ /əʊ/ /ɪə/ /eə/ /ʊə/`。

## 学习顺序

### 阶段 1：核心元音与最小对立

课程 01–10，顺序为 `/iː/ /ɪ/ /ɛ/ /æ/ /ʌ/ /ə/ /uː/ /ʊ/ /ɑ/ /ɔ/`。优先建立元音听觉坐标，并把容易混淆的音成对教学。

### 阶段 2：卷舌元音与双元音

课程 11–17，顺序为 `/ɝ/ /ɚ/ /eɪ/ /aɪ/ /ɔɪ/ /aʊ/ /oʊ/`。重点是美式卷舌色彩和双元音连续滑动。

### 阶段 3：爆破音

课程 18–23，顺序为 `/p/ /b/ /t/ /d/ /k/ /g/`。按清浊成对，训练送气、声带振动和词尾收音。

### 阶段 4：摩擦音

课程 24–32，顺序为 `/f/ /v/ /θ/ /ð/ /s/ /z/ /ʃ/ /ʒ/ /h/`。重点纠正 `/v/`、`/θ/`、`/ð/` 等中文母语者常见问题。

### 阶段 5：破擦音与鼻音

课程 33–37，顺序为 `/tʃ/ /dʒ/ /m/ /n/ /ŋ/`。

### 阶段 6：流音与半元音

课程 38–41，顺序为 `/l/ /r/ /j/ /w/`。重点训练美式 `/r/`、暗 L 和 `/v/–/w/` 区分。

阶段顺序用于引导，但不强制锁住后续内容：用户始终可查看并进入任意音标。

## 页面设计

### 首页

采用已确认的“完整学习地图”版式：

- 顶部展示产品名、学习地图、听辨训练、最小对立和复习入口。
- 首屏说明“每天 15 分钟、约 6 周完成基础路线”，并提供“从第 1 课开始”主按钮。
- 摘要区展示 41 个音、6 个阶段、建议每日时长和复习机制。
- 主体用 6 张阶段卡片完整展示 41 个音；每个音显示课程编号。
- 黄色标记表示中文母语者重点易错音。
- 已学、正在学和未学通过状态样式区分，但未学内容仍可点击。

### 单音学习页

每个音使用一致的五步结构：

1. 听标准孤立音：正常速度、慢速、重复三次。
2. 看发音方法：嘴唇、舌位、声带和气流说明；口型示意默认展开。
3. 学高频例词：优先 3–5 个美式例词，显示现代美式音标并播放录音。
4. 做最小对立：与最容易混淆的音成对听辨和跟读。
5. 完成自测：四选一听辨；答对后标记当前音为已学，答错进入复习列表。

单音页底部提供上一课、返回地图和下一课。

### 专项训练

- 听辨训练：从已学音标中随机出题；不足 4 个时从当前阶段补充干扰项。
- 最小对立：按 `/iː/–/ɪ/`、`/ɛ/–/æ/`、`/uː/–/ʊ/`、`/θ/–/s/`、`/ð/–/z/`、`/v/–/w/`、`/l/–/r/` 等分组。
- 我的复习：汇总答错音和用户手动收藏的音。

## 发音与内容质量

- 只使用美式录音。现有 `WUS_*.mp3` 可在文件名、例词和目标音一致时复用。
- `WUK_*.mp3` 不进入新站点的数据清单和播放路径。
- 每个孤立音必须映射到现代美式 KK 符号；旧符号不能通过别名直接显示给用户。
- 对现有录音做完整性审计：数据引用与磁盘文件一一对应、音频可解码、无零字节文件。
- 浏览器系统语音仅作为缺失录音时的明确降级方案，不冒充已校验的标准录音。
- 例词音标、目标音高亮和录音必须对应；不能继续沿用英式底表。

## 技术结构

保留零构建、无框架的模块化静态站：

- `index.html`：页面骨架和无 JavaScript 时的基础说明。
- `assets/styles.css`：响应式布局、学习状态和主题。
- `src/data/phonemes.js`：41 音、分类、顺序、发音说明、例词和对立组。
- `src/audio.js`：单实例播放、慢速、重复、错误处理。
- `src/progress.js`：`localStorage` 学习进度、错题和收藏。
- `src/app.js`：路由状态、页面渲染和事件绑定。
- `audio/`：实际被现代美式 KK 数据引用的录音。
- `tests/`：数据一致性和静态资源检查脚本。

页面使用 URL hash 表达视图，例如 `#/map`、`#/sound/i-long`、`#/quiz`，以兼容 GitHub Pages 静态托管和浏览器前进/后退。

## 状态与错误处理

- 进度只存匿名本地数据，不需要登录或后端。
- `localStorage` 不可用时仍允许学习，只是不保存进度，并显示一次非阻塞提示。
- 音频加载失败时显示具体文件名和重试按钮，不静默切换到错误口音。
- 数据缺少例词、音标或录音时，自动化检查失败，阻止发布。

## 测试与验收

- 数据检查：恰好 41 个唯一音素；课程编号连续；所有音只属于一个阶段。
- 内容检查：不存在 `WUK_` 以及已删除的英式符号；每个音至少有一个例词和一个可播放目标。
- 资源检查：所有引用的 mp3 存在且非空，没有未引用录音进入发布产物。
- 浏览器验收：桌面和手机宽度下完成“首页 → 第 1 课 → 播放 → 自测 → 返回地图”。
- 发布验收：GitHub Pages 线上 URL 返回 200，首页加载无控制台错误，至少验证一个孤立音和一个例词录音。

## 发布

- 在 GitHub 账号 `StayGoldTY` 下创建公开仓库 `Phonetic-Symbol`。
- 保留 Cursor Origin 远端作为现有备份；GitHub 使用独立远端名，避免覆盖 `origin`。
- GitHub Actions 在 `main` 分支每次推送后运行检查并部署 GitHub Pages。
- 后续每次完成修改，都提交并推送到 Cursor Origin 与 GitHub；Pages 工作流自动发布，任务结束时分别报告本地、提交、推送、部署和线上验证状态。
