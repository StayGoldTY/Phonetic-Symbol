# Phonetic-Symbol

美音优先的 48 个国际音标跟练页。内容来自本地「学音标」页面：每个音标有孤立音、例词、例句、最小对立和听音自测。

## 怎么打开

录音在 `audio/` 里，页面用相对路径读取，直接双击 `index.html` 即可。播放会先停掉上一段声音。

顶部默认是美音。例词主标按美音（GA），英式音标以灰字备注。橙色加粗是当前卡片要练的音。

## 目录

- `index.html`：跟练页（音标数据、口型示意、自测都在这一页）
- `audio/P_*.mp3`：音素孤立音
- `audio/D_*.mp3`：个别双元音的孤立音
- `audio/WUS_*.mp3`：美音例词
- `audio/WUK_*.mp3`：英音例词，切到「英音」时优先使用

没有单独录音的音（例如 /eɪ/、/tr/）会改播对应例词。
